# IP status

21 August 2026

This code was written in 2013 for a self-funded, taught MSc at the University
of East London. It was not part of a sponsored or externally funded research
programme.

Under UEL's Terms of Admittance, students are entitled to the intellectual
property rights in work they create that would belong to them under
applicable law, and any UEL claim over IP arising from a taught programme
should have been set out in the published programme information for that
course. On that basis the author's understanding is that copyright in this
software rests with the author.

An email requesting written confirmation from UEL was sent on 21 August 2026
to r.a.support@uel.ac.uk. No reply has been received yet.

The MIT licence in this repository reflects the author's current
understanding of the IP position. This file will be updated with UEL's
response once received. If that response differs from the position above,
the licence and this file will be corrected without delay.
